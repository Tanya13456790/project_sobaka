Цель работы: разработать поэтапный план создания учебного курса по работе с роботом-собакой, включающий анализ аппаратного устройства и проектируемого ПО.

Ход работы
Процесс разработки проекта разделяется на три основных этапа:
-Проектирование графического интерфейса и архитектуры приложения 
-Разработка логики управления и эмуляция работы с роботом 
-Интеграция с реальным роботом и финальное тестирование 

Этап 1 - проектирование дизайна 
Название: Проектирование графического интерфейса и архитектуры приложения
Содержание:
Анализ требований к интерфейсу: какие функции должны быть доступны пользователю (управление движением, просмотр видео с камеры, отображение статуса);
Выбор технологического стека: Python + PyQt5 / PySide6 (кроссплатформенность, скорость разработки);
Проектирование макета главного окна:
-Область для отображения видеопотока (QLabel, фиксированный размер 640×480);
-Блок кнопок управления: «Поднять», «Положить», «Вперёд», «Назад», «Влево», «Вправо», «Поворот влево», «Поворот вправо», «СТОП»;
-Панель статуса для отображения состояния подключения и ошибок;
Создание прототипа интерфейса в Qt Designer (сетка кнопок, цветовое выделение кнопки СТОП);
Проектирование архитектуры приложения:
-Класс Go2RobotController — управление роботом (методы: connect(), move_forward(), stand_up(), _safe_move() и др.);
-Класс MainWindow — графический интерфейс (обработчики нажатия кнопок, отображение видео);
-Механизм сигналов/слотов для связи интерфейса с логикой;
Создание UML-диаграммы классов проекта;
Создание схемы взаимодействия компонентов (ПК → WebRTC → робот).

Этап 2 - разработка логики 
Название: Разработка логики управления и эмуляция работы робота
Содержание:
1.Реализация базового каркаса приложения на Python + PyQt5;
2.Создание заглушек (stub/mock) для команд робота (эмуляция, когда реального робота нет);
3.Реализация графического интерфейса по разработанному макету;
4.Реализация безопасного управления: команда «один шаг + автоматическая стабилизация» на каждое движение (как указано в правилах безопасности);
5.Эмуляция видеопотока: загрузка тестового видеофайла или статического изображения вместо реальной камеры;
6.Обработка ошибок: вывод сообщений при попытке выполнить команду без подключения;
7.Создание инсталлятора или инструкции по запуску приложения;
8.Тестирование интерфейса и логики в автономном режиме (без реального робота).

Этап 3 - тестирование 
Название: Интеграция с реальным роботом и финальное тестирование
Содержание:
-Установка операционной системы Ubuntu 22.04 LTS (рекомендуемая для работы с роботом);
-Установка необходимых пакетов: Python 3.8+, pip, PyQt5, OpenCV;
-Установка библиотеки для WebRTC-подключения;
-Подключение компьютера к роботу через Wi-Fi;
-Замена заглушек на реальные вызовы библиотеки unitree_webrtc_connect;
-Получение и отображение реального видеопотока с камеры робота;
-Тестирование каждой команды управления на реальном роботе;
-Проверка автоматической стабилизации после каждого движения;
-Проверка реакции на потерю связи (робот должен остановиться);
-Тестирование на различных дистанциях (в пределах зоны действия Wi-Fi);
-Сбор обратной связи, исправление выявленных ошибок;
Подготовка итогового отчёта и демонстрация работы программы.
